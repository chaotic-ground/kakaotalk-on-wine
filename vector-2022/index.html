From 카카오톡 on Wine

GNOME Wayland에서 한국어 카카오톡을 돌립니다. 패치한 Wine을 담은 flatpak 하나와, Wayland가 부족한 부분을 메우는 GNOME 확장 하나입니다.

카카오는 리눅스 클라이언트를 내지 않습니다. 윈도우용을 Wine으로 돌리는 것이 유일한 길인데, 그냥 돌리면 여러 가지가 어긋납니다. 이 꾸러미는 그 어긋난 것들을 하나씩 고쳐둔 것입니다.

되는 것

항목 어떻게
한국어 UI와 글꼴 됨
이모지 됨, 패치한 Wine(0001). 흑백입니다
두 손가락 스크롤 됨, 패치한 Wine(0002)
이미지·스크린샷 붙여넣기 됨, 패치한 Wine(0003, 0006)
QWERTY가 아닌 자판의 단축키 됨, 패치한 Wine(0004)
트레이 우클릭 메뉴 됨, 패치한 Wine(0005) + 확장
알림을 누르면 대화창이 앞으로 됨, 패치한 Wine(0007)
입력기를 바꾼 뒤 한글 입력 됨, 패치한 Wine(0010)
새 메시지 팝업 위치와 포커스 됨, 확장
알림이 남기는 유령 창 숨김, 확장
스크롤할 때 뜨는 날짜 위치 조정, 확장
Alt-Tab 아이콘과 이름 됨

알아둘 것

알림이 올 때는 창이 앞으로 나오지 않습니다. 일부러 그렇습니다. 윈도우도 같습니다. 배경 프로그램이 화면을 가로채려 하면 OS가 거절하고 작업 표시줄 단추만 깜빡입니다. 알림을 누르면 그때 올라옵니다.

이모지는 흑백입니다. 컬러 글리프를 그릴 길이 Wine의 텍스트 경로에 아예 없습니다. 글자는 나오고 색만 없습니다.

카카오톡 자체는 들어있지 않습니다. 카카오의 것이라 배포할 수 없습니다. 런처가 첫 실행 때 공식 설치 파일을 받아옵니다.

어디서 확인했나

Fedora 43, GNOME 49 Wayland, 패치한 Wine 11.18, 카카오톡 26.8(64비트).

고친 것들이 왜 고쳐야 했는지는 저장소의 patches/README.md에 하나씩 적혀 있습니다. 대부분 업스트림 Wine의 버그이고, 몇 개는 아직 업스트림에 열려 있는 채입니다.
