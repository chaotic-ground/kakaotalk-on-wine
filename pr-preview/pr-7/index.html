카카오톡 on Wine

From 카카오톡 on Wine
Jump to navigationJump to search

카카오톡 on Wine은 GNOME Wayland에서 한국어 카카오톡을 돌리기 위한 꾸러미입니다. 패치한 Wine을 담은 flatpak 하나와, Wayland가 부족한 부분을 메우는 GNOME 확장 하나로 이루어져 있습니다.

카카오가 리눅스 클라이언트를 내놓지 않는 이상 윈도우용을 Wine으로 돌리는 수밖에 없는데, 그냥 돌리면 글꼴부터 클립보드까지 여러 가지가 어긋납니다. 이 꾸러미는 그렇게 어긋나는 것들을 하나씩 찾아 고쳐두었습니다.

주의 사항

알림과 창

알림이 올 때 창이 앞으로 나오지 않는 것은 일부러 그렇게 둔 것이고, 윈도우에서도 사정은 같습니다. 배경에 있는 프로그램이 화면을 가로채려 하면 OS가 그 요청을 거절하고 작업 표시줄 단추만 깜빡여줍니다. 알림을 누르면 그때 올라옵니다.

이모지 색

Wine의 텍스트 경로에 컬러 글리프를 그릴 길이 없어서 글자는 제대로 나오고 색만 빠집니다. 자세한 것은 패치/0001에 적어두었습니다.

카카오톡 본체

카카오의 것이라 이 꾸러미에 함께 넣어 배포할 수 없습니다. 런처가 첫 실행 때 공식 설치 파일을 받아옵니다.

고친 것

여기서 고친 것은 대부분 업스트림 Wine의 버그이고, 아직 열려 있거나 신고된 적조차 없는 것이 많습니다. 자세한 내용은 각 문서를 참고하십시오.

번호 증상 건드리는 곳 업스트림
0001 이모지가 빈 상자 두 개로 나옴 win32u bug 53929, 2022년부터 열려 있음
0002 두 손가락 스크롤이 아무 일도 안 함 winewayland.drv/wayland_pointer.c 56043, 57709. 둘 다 열려 있고 UNCONFIRMED
0003 브라우저에서 복사한 그림이 안 붙음 winewayland.drv/wayland_data_device.c 안 냈습니다
0004 드보락에서 Ctrl+V가 각인이 V인 키에서 동작 winewayland.drv/wayland_keyboard.c 안 냈습니다
0005 트레이 우클릭 메뉴가 어디에도 안 뜸 winewayland.drv/window.c 안 냈습니다
0006 GNOME 스크린샷이 안 붙음 winewayland.drv/wayland_data_device.c 안 냈습니다. 이대로는 받지 않을 것입니다
0007 알림을 눌러도 대화창이 뒤에 그대로 있음 winewayland.drv 일곱 곳과 xdg-activation 프로토콜 xml 안 냈습니다
0008 입력기를 바꾼 뒤 레이아웃이 안 따라옴 winewayland.drv/wayland_keyboard.c 안 냈습니다
0009 조합하던 글자가 오는 족족 취소됨 winewayland.drv/window.c 안 냈습니다
0010 입력기를 바꾸면 입력이 통째로 삼켜짐 imm32/imm.c 안 냈습니다

확인한 환경

Fedora 43, GNOME 49 Wayland, 패치한 Wine 11.18, 카카오톡 26.8(64비트).
