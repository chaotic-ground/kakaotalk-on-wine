From 카카오톡 on Wine

카카오톡 on Wine은 GNOME Wayland에서 한국어 카카오톡을 돌리기 위한 꾸러미이다. 패치한 Wine을 담은 flatpak 하나와, Wayland가 부족한 부분을 메우는 GNOME 확장 하나로 이루어져 있다.

카카오는 리눅스 클라이언트를 내지 않는다. 윈도우용을 Wine으로 돌리는 것이 유일한 길인데, 그냥 돌리면 여러 가지가 어긋난다. 이 꾸러미는 그 어긋난 것들을 하나씩 고쳐둔 것이다.

되는 것

항목 어떻게
한국어 UI와 글꼴 됨
이모지 됨, 패치 0001. 흑백이다
두 손가락 스크롤 됨, 패치 0002
이미지·스크린샷 붙여넣기 됨, 0003과 0006
QWERTY가 아닌 자판의 단축키 됨, 패치 0004
트레이 우클릭 메뉴 됨, 패치 0005 + 확장
알림을 누르면 대화창이 앞으로 됨, 패치 0007
입력기를 바꾼 뒤 한글 입력 됨, 패치 0010
새 메시지 팝업 위치와 포커스 됨, 확장
알림이 남기는 유령 창 숨김, 확장
스크롤할 때 뜨는 날짜 위치 조정, 확장
Alt-Tab 아이콘과 이름 됨

주의 사항

알림이 올 때는 창이 앞으로 나오지 않는다. 일부러 그렇다. 윈도우도 같다. 배경 프로그램이 화면을 가로채려 하면 OS가 거절하고 작업 표시줄 단추만 깜빡인다. 알림을 누르면 그때 올라온다.

이모지는 흑백이다. 컬러 글리프를 그릴 길이 Wine의 텍스트 경로에 아예 없다. 글자는 나오고 색만 없다.

카카오톡 자체는 들어있지 않다. 카카오의 것이라 배포할 수 없다. 런처가 첫 실행 때 공식 설치 파일을 받아온다.

고친 것

업스트림 Wine의 버그 열 개이다. 대부분 아직 업스트림에 열려 있거나 신고된 적이 없다. 자세한 내용은 각 문서를 참고하라.

번호 증상 건드리는 곳 업스트림
0001 이모지가 빈 상자 두 개로 나옴 win32u bug 53929, 2022년부터 열려 있음
0002 두 손가락 스크롤이 아무 일도 안 함 winewayland.drv/wayland_pointer.c 56043, 57709. 둘 다 열려 있고 UNCONFIRMED
0003 브라우저에서 복사한 그림이 안 붙음 winewayland.drv/wayland_data_device.c 안 냈다
0004 드보락에서 Ctrl+V가 각인이 V인 키에서 동작 winewayland.drv/wayland_keyboard.c 안 냈다
0005 트레이 우클릭 메뉴가 어디에도 안 뜸 winewayland.drv/window.c 안 냈다
0006 GNOME 스크린샷이 안 붙음 winewayland.drv/wayland_data_device.c 안 냈다. 이대로는 받지 않을 것이다
0007 알림을 눌러도 대화창이 뒤에 그대로 있음 winewayland.drv 일곱 곳과 xdg-activation 프로토콜 xml 안 냈다
0008 입력기를 바꾼 뒤 레이아웃이 안 따라옴 winewayland.drv/wayland_keyboard.c 안 냈다
0009 조합하던 글자가 오는 족족 취소됨 winewayland.drv/window.c 안 냈다
0010 입력기를 바꾸면 입력이 통째로 삼켜짐 imm32/imm.c 안 냈다

확인한 환경

Fedora 43, GNOME 49 Wayland, 패치한 Wine 11.18, 카카오톡 26.8(64비트).
